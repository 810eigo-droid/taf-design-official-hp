## 0. 最初に — 「開封されない」の原因切り分け

文面を攻める前に、これを確認してください。文章の問題ではない可能性があります。

| 確認項目 | なぜ効くか | やること |
|---|---|---|
| **SPF / DKIM / DMARC** | 未設定だと Gmail・Yahoo に高確率で迷惑メール送りされる。2024年以降 Gmail は一括送信者に必須化 | taf-design.com のDNSに3つとも設定。Gmailの「メールを表示 → メッセージのソースを表示」で `SPF: PASS / DKIM: PASS / DMARC: PASS` を確認 |
| **送信元名** | 「ティーチ&ファネルDesign」より「福田（ティーチ&ファネルDesign）」のような**個人名**のほうが開封率が上がる | 差出人名を個人名+屋号に |
| **HTMLメールか** | 画像だらけ・リンク大量のHTMLメールはプロモーションタブ行き。**テキスト主体**が強い | 下記原稿はテキスト主体で設計済み |
| **リンクの本数** | 多いほど迷惑メール判定に近づく。5本以内が目安 | 原稿ではCTAを3本+資料1本に絞った |
| **短縮URL・トラッキング画像** | 到達率を下げる要因 | lin.ee は例外として、他は素のURLで |
| **1通目の送信タイミング** | 資料請求の直後（1分以内の自動返信）が最も開封される瞬間 | 自動返信をこの原稿に差し替える |

**結論**: 開封率が測れないなら、まず「自分の Gmail / Yahoo / iCloud の3アカウントに送って、受信トレイに入るか」をテストしてください。プロモーションタブや迷惑メールに落ちているなら、原稿を何度直しても意味がありません。

## 1. 設計思想 — 1通目を「ミニLP」にする

読まれるのは1通目だけ。だから**この1通を、資料のリンクを貼っただけの送り状ではなく、それ単体で申し込みまで完結する縦長LPとして書きます。**

### 5つの原則

1. **最初の3行で全部言う**
   スマホの通知プレビューとリスト表示で見えるのは件名+冒頭30〜40文字。ここに「20,000円」「7日」「月額0円」の数字を置く。挨拶文から始めない。

2. **読まない人のために「3行まとめ」を冒頭に置く**
   全部読む人は2割。残り8割は冒頭とP.S.しか読まない。だから**冒頭とP.S.だけで意思決定できる**ように書く。

3. **資料リンクは冒頭で渡す。CTA枠には入れない**
   今回の大前提は「資料も読まれない」です。ということは、**資料リンクは"次にとってほしい行動"ではなく、約束の履行**です。冒頭で即座にお渡しして役目を終わらせ、CTA枠は行動3つだけに絞ります。12ページの資料を読むという最も重い行動を「次にできること」に並べると、他の2つの重みまで下がります。

4. **CTAを「温度別に3本」並べる**
   これが今回の最大の変更点。今までは資料DLリンク1本だったはずです。人によって「今すぐ話したい」「見積もりだけ欲しい」「そもそも何を頼めばいいか分からない」と温度が違うのに、出口が1つしかないと、温度の合わない人は全員こぼれます。

   | 温度 | 出口 | 決めることの数 |
   |---|---|---|
   | 熱い | **電話 10分**（番号と時間帯を返信するだけ・こちらから発信） | 2つ |
   | **迷っている** | **予算から選ぶ /budget/**（予算帯を1つ選ぶだけ） | **1つ** |
   | 決まっている | **かんたん見積もり /order/**（15項目・48時間以内に返信） | 15 |

   **中央の /budget/ が実は本命**です。理由は切り口案11を参照。

5. **P.S. を2本入れる**
   本文を飛ばした人がほぼ必ず読むのがP.S.。1本目に「電話10分」、2本目に「はじめての方へ(ココナラ経由の安心な注文方法)」を置く。

6. **「送りっぱなしにしない宣言」を書く**
   「この後こちらから追いかけるメールは送りません。必要な時にこの1通を見返してください」と明言する。これは正直であると同時に、**この1通を保存させる**ための仕掛けです。しつこい営業をしないというブランドトーンとも一致します。

## 2. 「攻める」ための切り口 10案

「攻める」＝声を荒げることではなく、**他社が言えないことを言い切る**ことです。使えそうなものを選んでください。

### 案1: 敵を名指しする（最も効く・資料のストーリーをメール冒頭に前倒し）
> 「その見積もり、半分は"いらない費用"かもしれません。」

Web制作が30万円する理由は、技術ではなく**人月と往復の回数**であることを言い切る。既に service-guide.html のストーリーにある論法ですが、**資料を開かない人には届いていない**。だからメール本文に持ってくる。

### 案2: 相見積もりの当て馬宣言（逆張り）
> 「他社さんの見積もりと並べて比べてください。当て馬で構いません。むしろ、並べたときにいちばん違いが出るのがうちです。」

「検討中です」と言われて終わる案件を、その場で土俵に上げる一文。自信の表明として最も強い型です。

### 案3: 損失を時間で数える
> 「ホームページがない・古いまま、という状態は"何も起きていない"のではなく、毎日静かに機会を失っている状態です。」

利益の提示より損失回避のほうが人は動きます。ただし煽りすぎると信用を損なうので、**断定せず1文だけ**にとどめる。

### 案4: 納期で殴る
> 「3ヶ月かかっていた制作を、平均7日に。今日ご相談いただければ、今月中にはもう公開されています。」

価格より納期のほうが驚かれます。価格は「安かろう悪かろう」を疑われますが、納期は疑いようがない。

### 案5: リスクをこちらが全部持つ（7つの約束を箇条書きに）
月額0円 / 買い切り / サブスクなし / 追加費用は必ず事前に文書で相談 / 見積もり返信48時間以内 / しつこい営業は一切しない / 電話は希望者のみ・こちらから発信。
**「断りやすさ」を明示するほど、問い合わせは増えます。**

### 案6: 電話のハードルを徹底的に削る
> 「電話番号と、都合の良い時間帯だけ返信してください。こちらから10分だけお掛けします。10分で切ります。売り込みはしません。電話が苦手なら、チャットだけで最後まで進めても大丈夫です。」

電話受付を始めたのに使われないのは、たいてい**「かける」側の手間**が原因。**「こちらから発信」「10分で切る」「電話なしでもOK」**の3点セットで心理コストをゼロにする。

### 案7: サーバー未契約の人を取りこぼさない（0円公開セットを封じ手にしない）
> 「サーバーを契約していなくても大丈夫です。月額費用のかからない公開スペースに設置する方法があります（設定込み3,300円）。」

これは今まで見積もり対話の切り札として温存されていますが、**1通完結メールでは前に出す価値があります**。「サーバーがまだ」という理由で止まっている見込み客が、この1行で動きます。
※ HTML納品限定・URLは簡易的、という条件は必ず併記。技術名は書かない。

### 案8: 選択肢A/B/Cで返信のハードルを下げる
既に見積もりアシスタントの返信テンプレで使っている型を、**1通目に前倒し**する。
> 「A・B・Cのどれか一文字だけ返信してくだされば、そこから始めます。」
返信する文章を考えなくていい状態にするのが目的。

### 案9: 価格を全部書いてしまう
問い合わせないと値段がわからない、が最大の離脱要因。**主要メニューの価格を表で全部載せる**。「聞かないとわからない」を消すと、逆に問い合わせは増えます。

### 案10: 期限を作る（要オーナー判断）
**「今月の新規着手は◯社まで」**という枠の制限を置くと締まります。
**ただし実態と違う数字は書かないこと。** 実際に回せる社数がわかっているときだけ使ってください。

### 案11: 「予算から選ぶ」を主CTAに引き上げる ★最重要
> 「何を頼めばいいか分からなくて大丈夫です。予算だけ決めてください。残すもの・後回しにするものは、こちらが設計します。」

見込み客が動かない最大の理由は、価格ではなく**「何を頼めばいいか分からない」**です。
根拠は見積もりアシスタントの鉄則1 —「全部盛り+低予算の依頼が多い（5サービス選択で予算2万円）」。これはお客様が**順番を知らない**という証拠そのものです。`/budget/` はその唯一の詰まりを解くページなので、資料や料金表より優先度が高い。

**4つの利点**

| | 内容 |
|---|---|
| 決断が1回で済む | `/order/` は15項目、電話は番号を渡す抵抗がある。予算帯を1つ選ぶだけが最も軽い |
| 選別になる | 「〜2万」を選んだ人と「10万以上」を選んだ人では、返信の書き分けも優先度も変わる。**メール経由の流入がどの帯に偏るかが分かれば、次の打ち手が決まる** |
| 「予算がなくて申し訳ない」を消す | 低予算を恥じて問い合わせない層が一定数います。予算帯が並んでいるだけで「〜2万でも客として想定されている」と伝わる |

**書き方の注意**: ページタイトルの「**先に、ご予算を教えてください**」は、こちらから見れば合理的ですが、まだ何も約束していない相手には**要求**に聞こえます。メール本文では必ず**「予算だけ決めれば、あとはこちらが設計します」という提供の形に反転**させてください（/budget/ ページ自身のリード文がすでにその形になっています）。

**さらに: 予算帯4行をメール本文にベタ書きする。**
クリックしない人にも自己診断させるためで、「1通完結」の方針とも一致します。リンクは「もっと詳しく見る」の位置づけに後退させる。

※ `/budget/` は公式HP（taf-design-official-hp）側の管轄です。ページ自体を直す場合は別セッションになります。

## 6. 運用メモ

- **自動返信に仕込む**: 資料請求フォームの自動返信を、この原稿に差し替えるのが最優先。資料請求の直後1分以内が最も開封される瞬間です。
- **「追いかけない」と書いた以上、追いかけない**: ただし**同じ内容を件名だけ変えて1回だけ再送**するのは有効です（3〜5日後・件名は案2または案4に変更）。1通目が迷惑メールに落ちていた人を拾えます。これは「新しい売り込み」ではなく「届かなかったものの再送」なので、書いた約束とも矛盾しません。
- **測る**: 開封率が取れないなら、`/budget/` `/order/` の流入を「メール経由」で見分けられるようにしておく（URLに `?from=mail` を付けるだけでも十分）。とくに **`/budget/` でどの予算帯が選ばれたかは、いま最も価値のあるデータ**です。〜2万に偏るなら単価の上げ方を、5〜10万に偏るなら上位プランの見せ方を、それぞれ次の打ち手として変えられます。
- **`/budget/` 側でやっておくと効くこと**（公式HP側セッションの管轄）:
  - 予算帯を選んだ後の出口に**電話相談を追加**する。いま `/budget/` → `/order/` の導線はありますが、電話は資料・LP・フォーム側にしか入っていないはずです。予算を決めた直後は最も温度が高い瞬間なので、ここに「10分だけ電話しますか」を置く価値が高い。
  - 各予算帯に**「この予算でできること」の実例を1つずつ**添える（金額だけでなく完成イメージがあると決めやすい）。
- **返信A/B/Cの受け皿**: 「A」だけの返信が来たときの一次対応文を用意しておくこと。電話希望の場合は、いただいた時間帯の中から**具体的な候補日時を2〜3個提示**して確定させる（見積もりアシスタントの鉄則7と同じ）。
