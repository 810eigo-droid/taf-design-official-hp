## STEP 1. Google広告アカウントを作る(エキスパートモード・キャンペーンなし)

1. https://ads.google.com/ を開き、**810eigo@gmail.com**(GA4と同じGoogleアカウント。2026-09-23 オーナー確認。caucasus189 ではない)でログイン → 「今すぐ開始」
2. ビジネス名 `TAF-design`、ウェブサイト `https://taf-design.com` を入力
3. キャンペーン作成の誘導画面が出たら、画面下の小さな文字 **「エキスパートモードに切り替え」** を押す
   (または「キャンペーンの作成をスキップ」「キャンペーンなしでアカウントを作成」)
4. **「キャンペーンなしでアカウントを作成」** を選ぶ
5. 請求先の国: 日本／タイムゾーン: **(GMT+09:00) 日本時間**／通貨: **日本円(JPY)**
   ※ タイムゾーンと通貨は**後から変更できない**。必ず確認
6. お支払い情報(クレカ)を登録 → 送信

> ここで「スマートモード(簡易版)」のまま進めてしまった場合は、右上の設定から「エキスパートモードに切り替え」。

## STEP 2. 自動適用のおすすめをすべてオフ

左メニュー **キャンペーン → おすすめ → 右上「自動適用」** → すべてのチェックを外して保存。
(部分一致への自動拡張・広告文の自動生成を防ぐ)

## STEP 3. GA4とリンクする

**Google広告側から:**
1. 左メニュー **ツール → データマネージャー**(旧: 設定 → リンクアカウント)
2. **Google アナリティクス(GA4)** → 「管理」または「リンク」
3. プロパティ **「TAF Design HP」(プロパティID 544461036・測定ID G-7MPQKJVDD8)** の行で **リンク** → 「アプリとウェブのアナリティクスの指標をインポート」をオン → 保存

**うまくいかない場合はGA4側から:**
GA4 → 管理(歯車) → プロダクトのリンク → **Google 広告のリンク** → リンク → 作成したGoogle広告アカウントを選択 → 「パーソナライズド広告を有効化」「自動タグ設定を有効化」オンのまま → 送信

**確認:** Google広告の データマネージャー で GA4 が「リンク済み」になっている。

## STEP 4. 計測されるイベント(理解用・作業なし)

どのフォームも GA4 には同じ `generate_lead` を送る。Google広告ではこれ1つをコンバージョンにする。
キャンペーンA/Bどちらから来たかは、Google広告のキャンペーン別レポートで分かれる。

| ページ | いつ送られるか | form_id | 実装 |
|---|---|---|---|
| /offer2/ 資料請求 | CF7送信完了 | `offer2` | 設置済み |
| /tel/ 電話相談 | CF7送信完了 | `tel` | 設置済み |
| **/order/ 見積もり** | 入力チェック通過後に「LINEで送る」「メールで送る」を押したとき | `order`(method: line / mail) | **2026-09-23追加。WPへの貼り替えが必要(STEP 0-3)** |

※ /order/ はフォーム送信ではなくLINE/メールへ引き継ぐ作りなので、「送る意思を示した時点」で数える。
実際にLINE/メールが届いた件数と月1回見比べて、ズレが大きければ価値(STEP 5)を下げる。

## STEP 5. GA4のキーイベントをコンバージョンとしてインポート

1. Google広告 **目標 → 概要(またはコンバージョン → 概要) → 「+ コンバージョンアクションを作成」**
2. **「インポート」 → 「Google アナリティクス 4 プロパティ」 → 「ウェブ」** → 続行
3. 一覧から **`generate_lead`** にチェック → インポートして続行 → 完了
4. 作成された `generate_lead`(GA4)の行を開いて **編集**:

| 項目 | 設定値 |
|---|---|
| 目標とアクションの最適化 | **メインのアクション**(＝入札に使う) |
| 値 | **すべてのコンバージョンに同じ値を使用: 3,000円**(仮。設計書§7) |
| カウント方法 | GA4インポートの場合は**Google広告側に項目が出ない**(GA4のキーイベント設定に従う。2026-09-23確認)。出ていれば「1回」 |
| クリックスルーCVの計測期間 | 30日(初期値のまま) |
| アトリビューションモデル | データドリブン(初期値のまま) |

5. 目標一覧の「リード」系の目標が **アカウントのデフォルト目標** になっていることを確認
6. もし Google広告側で **拡張コンバージョン**・**Googleタグの自動作成** を勧められても、今回はスキップでよい(GA4インポートで足りる)

## STEP 6. テスト送信で計上を確認

1. **スマホのモバイル回線**(自宅Wi-Fiは内部トラフィック除外されるため不可)で /offer2/ からテスト送信(名前に「テスト」)
2. GA4 → **レポート → リアルタイム** → イベント数に `generate_lead` が出る(数分以内)
3. /order/ でも同様に、相談内容を1つ選んで「メールで送る」→(メールは送らなくてよい)→ リアルタイムに `generate_lead` が出る
4. Google広告側の `generate_lead` のステータスが **「コンバージョンなし」→「記録中」/「有効」** になるまで数時間〜1日

> Google広告の「コンバージョン」列に数字が乗るのは**広告クリック経由の送信だけ**。テスト送信は広告経由でないので、Google広告側の数値は0のままで正常。確認はGA4リアルタイムとステータス表示で行う。
