2. 現在の index.html をダウンロードしてバックアップ。
3. 配布ZIPの index.html、css/blog-feed.css、js/blog-feed.js、articles/index.html を同じ位置にアップロード。フォルダ全体を置き換えず、指定4ファイルだけ追加・更新。
4. トップ下部に5件、すべての記事を見るから一覧に5件表示されることを確認。
5. スマホでも確認。元に戻す場合はバックアップの index.html を戻す。
