# Google広告 立ち上げ設計書（自社集客｜広告 → LP → 資料請求 → メール → 電話）

> 目的: Google検索広告から資料請求を獲得し、**電話相談に持ち込んで受注する**。
> 前提: 電話相談は 2026-08-04 導入済み（無料・10分程度・希望者のみ・こちらから発信）。
> 価格の原本は このリポジトリの `docs/price-master.md`。
> 作成: 2026-08-05

---

## 0. 先に結論 — 今のままでは回せません。塞ぐべき穴が3つ

| # | 穴 | なぜ致命的か | 対応 |
|---|---|---|---|
| 1 | **受け皿LPに計測タグが無い**（Meta Pixelのみ。GA4もGoogle広告タグも未設置） | コンバージョンが測れない＝Googleの自動入札が学習できない。**予算を捨てることになります** | §7 |
| 2 | **/offer2/ の資料請求フォームに電話番号欄が無い**（お名前+メールのみ） | 「電話に持ち込む」導線が**構造として存在しない**。今はメールで番号をもらうしかない | §6 |
| 3 | **22,000円の商材を検索広告で直接売ると採算が合わない** | 受注1件あたりの広告費が単価を超えます（§3で試算） | §3 |

**3番について**: これは方針の否定ではなく、**「資料請求 → 電話」という進め方が正しい理由**です。22,000円を単発で売るのではなく、電話で「事業に効く順番」を提案して適正単価に持ち上げる。その設計でないと検索広告は回りません。つまりご指示の方向で合っています。

**着手順**: ①計測 → ②電話番号欄 → ③広告 の順。逆にすると学習期間を丸ごと無駄にします。

```

  ┌─────────────────┬─────────────────┐
  │ 比較・検討層       │ 今すぐ客           │
  │ 「相場」「比較」    │ 「格安」「依頼」    │
  ↓                 ↓
  LP（taf-design.com/lp/）   /order/ かんたん見積もり
  ↓                          ↓
  /offer2/ 資料請求           48時間以内に返信
  （名前・メール・★電話番号）    ↓
  ↓                          電話 or チャットで詰める
  1通完結メール（docs/email-service-guide-allin1.md）

## 2. Meta広告との違い（ここを間違えると失敗します）

| | Meta広告 | Google検索広告 |
|---|---|---|
| ユーザーの状態 | 探していない。**割り込み** | **自分から検索している** |
| 有効な入口 | 資料請求（低コミット） | 見積もり・電話（高コミット）も通る |
| 刺さる訴求 | 気づき・共感（「まだ30万払ってますか」） | **答えそのもの**（「22,000円・7日・月額0円」） |
| LPの長さ | 長くて良い（教育が必要） | **短く・結論を上に**（答え合わせに来ている） |

現在のLPはMeta広告用に「AIの時代に、HP/LP制作は高いままおかしくないですか?」という**気づき型のFV**です。検索から来た人には遠回りなので、§5の改修を推奨します。

## 3. 採算ライン（着手前に必ず読んでください）

**以下はすべて仮の数字です。** 実測が出たら必ず置き換えてください。目的は「どこが壊れると赤字になるか」を先に知っておくことです。

```
クリック単価（CPC）           400円   ← 制作会社が競合。要キーワードプランナー確認
LP → 資料請求のCV率           10%
　→ 資料請求1件あたり        4,000円

資料請求 → 電話に至る率        25%
電話 → 受注率                 40%
　→ 受注1件あたりの広告費   40,000円  ← ★ここ
```

**LP制作 22,000円の単発受注では、1件取るごとに約18,000円の赤字**です。

### だからこうする（3本立て）

| 打ち手 | 内容 |
|---|---|
| **① 電話で単価を上げる** | 22,000円を入口商品と割り切り、電話で「順番」を提案する。成約特化LP 70,000円／ファネル一式 150,000円／メタ広告スタート 55,000円 が視野に入れば一気に黒字 |
| **② LTVで回収する** | 保守 月5,500〜11,000円／追加セクション 2,750円／2回目以降の制作。**受注時点でなく12ヶ月で採算を見る** |
| **③ CV率を上げる** | 資料請求CV率が10%→20%になれば受注CPAは半分の20,000円。§5・§6の改修はここに効きます |

### 撤退・調整ライン（先に決めておく）

- 資料請求のCPAが **8,000円** を超えたら、キーワードか受け皿を疑う
- **1ヶ月・3万円**を上限に「学習用の授業料」と割り切って回す。ここで判断材料を作る
- 検索語句レポートを**週1で必ず見る**。除外キーワード（§4）の追加が最大の節約になります

## 4. キャンペーン構成とキーワード

| **飛ばし先** | **/order/**（かんたん見積もり） | **/lp/ → /offer2/**（資料請求） |
| CV定義 | 見積もりフォーム送信 | 資料請求フォーム送信 |
| 予算配分 | 6 | 4 |

## 5. 受け皿の割り当てと、必要な改修

| 受け皿 | 用途 | 改修 |
|---|---|---|
| **/order/** | キャンペーンA | 改修不要（電話相談の条件分岐が既にある）。**要: CVタグ** |
| **/lp/**（Meta LP） | キャンペーンB | 下記の改修を推奨。**要: GA4 + CVタグ** |
| **/offer2/** | 資料請求 | **電話番号欄の追加が必須**（§6）。**要: CVタグ** |
| /budget/ | 迷っている人の受け皿 | 改修不要。LPからの導線として有効 |

### /lp/ の改修案（検索流入向け・優先度順）

1. **FV上部に「検索から来た人向けの答え」を1行足す**
   現在のFVは「AIの時代に、HP/LP制作は高いままおかしくないですか?」という問いかけ型。
   検索ユーザーは**答えを探しに来ている**ので、その上に結論を置く。
   > 例:「ホームページ制作 22,000円（税込）／月額0円／平均7日で公開」
2. **ファーストビューに電話番号を出す**（`tel:09025146064`）
   検索広告の顕在層は「今すぐ話したい」が一定数います。今のLPは電話導線がありません。
3. **CTAを2本にする** — 「資料請求（無料）」と「今すぐ見積もり」を並べる。
   ご希望の本線は資料請求なので、資料請求を主・見積もりを副で。

※ LP(lp/)も /offer2/・/order/ の控え(docs/wp-blocks/)も、このリポジトリで一元管理です(2026-08-24統一)。

## 6. /offer2/ に電話番号欄を追加する（「電話に持ち込む」の本体）

現在のフォームは **Contact Form 7（id: dd3556d）** のステップ形式で、項目は**お名前・メール・チェックボックスのみ**。電話番号を取っていないため、いまは「メールで番号を返信してもらう」以外に電話へ行く道がありません。

### 追加する項目（/order/ と同じ仕様に揃える）

```
■ 電話相談（無料・10分程度）
  ( ) 希望する（こちらからお電話します）
  ( ) 希望しない（メール・LINEで進めたい）

  ↓「希望する」を選んだときだけ表示
  ■ お電話番号　　［　　　　　　　］
  ■ 都合の良い時間帯　平日午前 / 平日午後 / 夕方以降 / 土日
```

### 書き方のルール（そのまま使ってください）

- **必須にしない。** 必須にすると資料請求そのもののCV率が落ちます。電話が苦手な層は確実にいます
- **「こちらからお掛けします」を明記。** かける手間をお客様に持たせない
- **「10分程度で終わります」を明記。** 拘束時間の不安が最大のブレーキです
- **「電話なしでチャットだけでも進められます」を必ず併記**（price-master の方針どおり）

### 期待できる効果

資料請求時点で番号をもらえれば、**メールが開封されなくても電話に進めます**。
今回の一連の課題（メールが読まれない）に対する、最も確実な回避策がこれです。

## 7. 計測設定（最初にやること）

現状:
- 公式HP `taf-design.com` … **GA4 あり**（`G-7MPQKJVDD8`）
- LP `taf-design.com/lp/` … **Meta Pixel のみ。GA4もGoogle広告タグも無し**

### 手順

1. **LPにGA4を入れる** — 公式HPと同じ `G-7MPQKJVDD8` を `/lp/index.html` の `<head>` に追加。これでLP→/offer2/ の遷移が一つの流れとして見えます
2. **Google広告のコンバージョンアクションを2つ作る**
   | 名前 | 発火点 | 価値 | 主要CVにするか |
   |---|---|---|---|
   | 資料請求 | /offer2/ の送信完了 | 3,000円（仮） | **する** |
   | 見積もり依頼 | /order/ の送信完了 | 8,000円（仮） | **する** |
   ※「価値」は自動入札の判断材料です。実測が出たら更新してください
3. **サンクスページを分ける**か、CF7の送信完了イベントでタグを発火させる
   ※ /offer2/ は送信後にJSで完了メッセージを出す作りなので、**ページ遷移が起きません**。URL到達型のCVは使えないので、**イベント発火型**で設定する必要があります。ここは実装が必要です
4. **電話タップも計測する** — LPに `tel:` リンクを置くなら、タップをCVとして拾う
5. GA4 と Google広告 をリンクし、GA4のコンバージョンをインポートできる状態にしておく

**入札戦略**: CVが月30件たまるまでは「クリック数の最大化（上限CPC設定あり）」。たまってから「コンバージョン数の最大化」へ。最初から自動入札にすると学習できず暴走します。

## 10. 確認が必要なこと

| 項目 | 内容 |
|---|---|
| CPCの実勢 | キーワードプランナーで「ホームページ制作 格安」等の実際の入札単価を確認。§3の400円は仮置きです |

| 予算上限 | §3では月3万円を学習用と置きましたが、実際に許容できる額をお決めください |
| LPの改修可否 | §5の改修（FV・電話番号・CTA2本）を入れるか。入れないなら資料請求CV率は現状のままと見込んでください |
| /offer2/ のCF7編集 | フォームIDは `dd3556d`。WordPress管理画面での編集になります |
```
