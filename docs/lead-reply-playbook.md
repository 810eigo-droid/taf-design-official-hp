# リード返信プレイブック(返事が来ない問題の対策)

> 症状: フォームからのリードに info@taf-design.com で手動返信しているが、返事が全くない。
> 結論: 原因はおそらく「届いていない」ではなく「返信しやすい形で送れていない」。ただし15分の到達テストで先に白黒つける。
> 作成: 2026-08-06 / 送信ルート前提: Gmailから差出人 info@taf-design.com(mail-tester 10/10確認済みルート)

---

## 0. まず事実を整理する

直近リードの通知メールを見ると、**メッセージ本文が空**。つまり:

- 相手は「質問」をしていない。**こちらの返信に"答える義務"が最初から無い**
- 「資料請求(資料だけ欲しい)」を選んだ人は、そもそも返信する気がない層。返信ゼロは異常ではない
- それでも受注につなげるのが返信の仕事 → 返信の中身と速さで勝負するしかない

「メールが届いていないのでは」という仮説は、認証(SPF/DKIM/DMARC 10/10)が済んでいる以上、可能性は低め。ただしYahoo宛(直近リードがyahoo.co.jp)は判定が厳しいので、§1のテストで確認してから文面の話に進む。

## 1. 15分の到達テスト(最初に1回だけやる)

1. 自分のGmail・Yahooメール(無ければ無料で作る)宛に、**実際のリード返信と同じ手順**で送る(Gmailの差出人=info@taf-design.com、件名も本文も本物と同じように)
2. 受信トレイ/迷惑メール/プロモーションのどこに入ったか確認
3. Gmail側で「メッセージのソースを表示」→ SPF: PASS / DKIM: PASS / DMARC: PASS を確認
4. Google Postmaster Tools で迷惑メール率・ドメイン評判を確認(登録済み)

**→ 受信トレイに入るなら、到達性は白。以降は文面と速度の問題**(たぶんこちら)。
**→ 迷惑メールに入るなら**: Gmailの「送信メールサーバー」設定がGmail経由になっていないか確認。エックスサーバーのSMTP(sv****.xserver.jp:587・info@taf-design.comで認証)経由に設定すると整合が取れる。

## 2. 返信の3原則

1. **当日返信**(遅くとも24時間以内)。夜のリードは翌朝一番。フォーム送信から時間が経つほど「誰だっけ」になる
2. **1通に価値を全部入れる**(価格・次の一歩・電話)。「詳しくはお打ち合わせで」は返信されない
3. **返信のハードルを一文字にする**。「A・B・C どれか一文字だけご返信ください」で締める。開いた質問(「どんなサイトをご希望ですか?」)は書かせる負担が大きく、無視される

### 追いメールのルール

- 返信が無くても**3日後に1回だけ**。件名を変えて同じ趣旨を短く(例: `その後いかがでしょうか|10分のお電話、いつでもどうぞ`)
- それ以上は追わない(ステップメール1/4/7日が並走しているため、手動でしつこくしない)
