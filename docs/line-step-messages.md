## 0. 配信設計(なぜこのスケジュールか)

- 資料請求者には**メールのステップが登録1・4・7日後に既に流れている**(MailPoet・自動化済み)。
  LINEで同じ時期に同じ内容を流すと「しつこい」ので、**LINEはメールが終わった後を受け持つ**。
- 週1回の間隔はOK。ただし**ダラダラ続けず4通で完結**させ、以降は月1回の手動配信(既に「LINEでセール・クーポン配信中」と公言しているため月1は必要)。
- **LINE公式アカウント無料プランは月200通まで**(あいさつメッセージはカウント外・ステップ配信はカウントされる)。
  友だち50人×月4通=200通で上限。友だちが増えたら通数か頻度を見直すこと。
  エルメ側のフリープラン上限(月1,000通)より、**LINE側の200通が先に効く**。

| 配信 | タイミング | 役割 |
|---|---|---|
| あいさつメッセージ | 友だち追加の直後(LINE公式の標準機能・無料) | お礼+資料リンク+「返信OK」 |
| ステップ1 | 追加から**7日後** 19:00 | 予算から選ぶ導線 |
| ステップ2 | 追加から**14日後** 19:00 | 実物を見てもらう+ココナラ星5 |
| ステップ3 | 追加から**21日後** 19:00 | 1分自動見積もり+電話相談 |
| ステップ4 | 追加から**28日後** 19:00 | 締め+今後は月1配信の予告 |

※19:00は仮。スマホを見る時間帯(19〜21時)なら変更可。
※資料請求せずにLINEだけ追加した人にも成立する文面にしてある(「資料請求済み前提」の書き方をしない)。

## 6. エルメでの設定手順

1. エルメ管理画面 → **メッセージ → ステップ配信** → 新規作成
2. シナリオ名: `新規友だち_4週ステップ`
3. 配信対象(トリガー): **友だち追加時**(全員)
4. ステップを4つ登録:
   - 1通目: 追加から **7日後 19:00** → §2の文面
   - 2通目: 追加から **14日後 19:00** → §3の文面
   - 3通目: 追加から **21日後 19:00** → §4の文面
   - 4通目: 追加から **28日後 19:00** → §5の文面
5. あいさつメッセージ(§1)は**ステップ配信に入れない**
   (LINE公式の標準機能なら無料枠を消費しないため。エルメの「あいさつメッセージ」機能で設定してもよい)
6. **テスト**: 自分のスマホの別アカウント(または家族のLINE)で友だち追加し、
   あいさつが即時に届くこと・ステップ1が7日後に予約されていることを確認
7. 有効化

### 運用の注意

- [ ] LINE公式アカウント管理画面で**月の配信数を月末に確認**(無料200通。超えそうなら翌月からステップを3通に減らす)
- [ ] 価格を文面に足すときは `docs/price-master.md` に同期
- [ ] クーポン・セールを打つときは月1配信(手動)で。ステップ文面には期限モノを入れない(自動配信で期限切れ事故になるため)
- [ ] 既存の友だち(ステップ開始前に追加済みの人)にはステップは流れない。必要なら月1配信でカバー
