# /tel/ 無料電話相談ページ — 作成手順(WordPress側)

> 作成: 2026-09-05 / 対象: 固定ページ「無料電話相談」(スラッグ `tel`)
> セットで使うもの: `tel.html`(カスタムHTMLブロックのガワ)
> 方針: **電話専用**。項目は お名前・電話番号・時間帯(必須)+ご相談内容(任意)。メールアドレスは取らない。
> 用途: LINEリッチメニュー「電話相談」ボタンの飛び先。Google広告の電話系導線にも使える。
> /offer2/(資料請求+任意の電話項目)は**変更しない**。

---

## 1. Contact Form 7 で新規フォームを作る

WordPress管理画面 → お問い合わせ → 新規追加。タイトル: `無料電話相談(tel)`

### フォームタブ(全選択して貼る)

```
<div class="field">
<label>お名前<span class="req">必須</span>
[text* your-name placeholder "ニックネーム可"]</label>
</div>

<div class="field">
<label>お電話番号<span class="req">必須</span>
[tel* tel-number placeholder "090-1234-5678"]</label>
</div>

<div class="field">
<p class="lbl">ご都合の良い時間帯<span class="req">必須</span></p>
[radio tel-time use_label_element default:2 "平日午前" "平日午後" "夕方以降" "土日・祝日" "いつでも可（早朝・深夜でもOK）"]
</div>

<div class="field">
<label>ご相談内容<span class="opt">任意</span>
[textarea tel-topic placeholder "「HPの金額を知りたい」など、一言でOKです。"]</label>
</div>

[submit "この内容で電話相談を申し込む"]
<p class="submit-note">送信後、お掛けする日時をSMSでお知らせします。無料・10分程度・こちらから発信します。</p>
```

### メールタブ(管理者宛て)

| 項目 | 値 |
|---|---|
| 送信先 | info@taf-design.com(既存フォームと同じ) |
| 送信元 | 既存フォームと同じ設定をコピー(WP Mail SMTP経由) |
| 題名 | `【電話相談】[your-name] 様 / [tel-time]` |
| 追加ヘッダー | (空欄。相手のメールは取らないので Reply-To なし) |

本文:
```
無料電話相談の申し込みがありました。

■お名前: [your-name]
■電話番号: [tel-number]
■時間帯: [tel-time]
■ご相談内容:
[tel-topic]

--
送信元ページ: https://taf-design.com/tel/
初動: 上の時間帯から候補を2〜3個、SMSで提示して日時を確定する(lead-reply-playbook 参照)
```

### メール(2)(自動返信)
**使わない**(メールアドレスを取らないため)。チェックを入れない。

### メッセージタブ
「送信完了」の文言は画面上でガワ(JS)が差し替えるので既定のままでOK。

### 保存 → ショートコードのIDを控える
作成済み(2026-09-05): `[contact-form-7 id="cf1e33b" title="無料電話相談(tel)"]`。`tel.html` にはこのIDが埋め込み済みなので、差し替え不要でそのまま貼れる。

## 2. 固定ページを作る

1. 固定ページ → 新規追加
2. タイトル: `無料電話相談`
3. スラッグ(パーマリンク): **`tel`** → URLは `https://taf-design.com/tel/`
4. カスタムHTMLブロックを1つ追加し、`tel.html` の中身を全部貼る(idを差し替え済みのもの)。グループに入れない
5. 他の固定ページ(/offer2/ など)と同じテンプレート・ヘッダー/フッター設定にする
6. 公開

---

## 3. MailPoet連携について(重要・何もしない)

WPCodeの「CF7→MailPoet 資料請求者リスト自動追加」スニペットは **offer2 のフォームID(dd3556d)を対象にしている**。
このフォームにはメールアドレス項目が無いので、**連携対象に追加しない**(追加すると空メールで登録エラーになる)。
電話相談の申込者にメールのステップは流れない。電話で直接フォローする。

---

## 4. 計測

- 送信完了時にガワ(JS)が GA4 へ `generate_lead`(`form_id: 'tel'`)を送る。ページにGA4タグ(G-7MPQKJVDD8)が入っていることが前提(WP全ページに設置済み)
- Google広告側では offer2 と同じ `generate_lead` としてカウントされる。分けて見たいときは GA4 で `form_id` をカスタムディメンション化する(急ぎでない)

## 5. 反映後の動作確認チェックリスト

- [ ] スマホ(390px相当)で表示が崩れない(3つの安心が縦並び・時間帯が2列)
- [ ] 名前・番号・時間帯が空のまま送信 → CF7の赤いエラーが出る
- [ ] 全角数字で番号を入れて送信 → 半角に直って送れる
- [ ] 送信成功 → 「電話相談のお申し込み、承りました」画面に切り替わり、選んだ時間帯が表示される
- [ ] info@taf-design.com に「【電話相談】○○ 様 / ○○」のメールが届く
- [ ] 「今すぐ話したい方」の番号をタップすると発信画面が開く(留守電の一文が出ている)
- [ ] GA4 リアルタイムで generate_lead(form_id=tel)が見える
