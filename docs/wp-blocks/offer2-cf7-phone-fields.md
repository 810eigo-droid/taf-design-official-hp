## 1. フォームタブに貼るスニペット

**最後の任意ステップ（ご質問・ご要望のtextarea）の直前**に、以下をそのまま貼ってください。
（`.field` の div 1個 = ステップ1画面。ガワのJSが自動でステップ数・進捗バーに反映します）

```html
<div class="field">
<span class="lbl">お電話でのご相談（無料・10分程度）<span class="opt">任意</span></span>
[radio tel-consult use_label_element default:2 "希望する（こちらからお電話します）" "希望しない（メール・LINEで進めたい）"]
<div class="tf-tel-detail">
<label>お電話番号
[tel tel-number placeholder "090-1234-5678"]</label>
<span class="lbl">ご都合の良い時間帯</span>
[radio tel-time use_label_element default:2 "平日午前" "平日午後" "夕方以降" "土日・祝日" "いつでも可（早朝・深夜でもOK）"]
</div>
<p class="tf-tel-note">※お電話が苦手な方は「希望しない」のままで大丈夫です。メール・LINEだけで最後まで進められます。<br>※こちらからお掛けします。早朝・深夜のご希望にも対応できますので、ご都合の良い時間をお選びください。<br>※内容が複雑な場合は、無料のZoom相談をご案内することもあります。</p>
</div>
```

### 仕様のポイント

| 項目 | 仕様 | 理由 |
|---|---|---|
| tel-consult | ラジオ・**「希望しない」を初期選択**（default:2） | 未回答をなくしてメールの受信内容を判別可能にする。必須化はしない |
| tel-number | `[tel]`・通常は非表示 | 「希望する」を選んだ時だけガワのJSが表示し、**その時だけ入力を要求**する（空のまま次へ進むとエラー、「希望しない」に戻せば通る） |
| tel-time | ラジオ・「平日午後」を初期選択 | 区分は /order/ フォーム準拠＋「いつでも可」を追加。**発信側は早朝・深夜も対応可能**（2026-08-06オーナー確認）なので時間帯を狭めない |

## 2. メールタブ（管理者宛て）に追記する行

受信メールの本文に以下を追加してください（既存項目の下でOK）。

```
■電話相談: [tel-consult]
■電話番号: [tel-number]
■時間帯: [tel-time]
```

※「希望しない」の場合、[tel-number] は空欄で届きます。
※自動返信メール（お客様宛て）には追記不要ですが、入れる場合は
「お電話をご希望いただいた方には、ご記入の時間帯にこちらからお掛けします」の一文を推奨。

## 3. ガワ側（カスタムHTMLブロック）が自動でやること

2026-08-05版の `offer2.html` に実装済み。CF7側の追加作業はありません。

- ラジオボタンをチェックボックスと同じカード風デザインで表示（時間帯は2列）
- 「希望する」選択で番号・時間帯エリアがスライド表示、番号欄へ自動フォーカス
- 番号の形式チェック（数字・ハイフン等10〜16文字。全角数字も許容）
- 送信完了画面に「📞 お電話のご希望、承りました！こちらからお掛けします」ボックスを表示（希望者のみ）
- 送信完了時に GA4 へ `generate_lead` イベントを送信（Google広告のコンバージョン計測用。
  **固定ページ側にGA4タグ（G-7MPQKJVDD8）が入っていることが前提**。gtagが無ければ何もしない安全設計）

## 4. 反映後の動作確認チェックリスト

- [ ] ステップ数が1つ増え、進捗バーの表示が正しい

- [ ] 「希望する」+番号空欄で「次へ」→ エラーが出る
- [ ] 「希望しない」のまま最後まで送信できる（番号なしで通る）

- [ ] 電話希望ありで送信 → 完了画面に📞ボックスが出る

## 5. 電話の運用ルール（2026-08-06 オーナー確認）

| 区分 | 運用 |
|---|---|
| **こちらから掛ける**（/offer2/ の電話相談） | 時間帯の制限なし。**早朝・深夜・土日も対応可**。着信音を鳴らさない運用のため、お客様のご都合を最優先で合わせる |
| **お客様から掛かってくる**（公式HP掲載の 090-2514-6064） | **通常は留守番電話**。メッセージを残していただければ折り返す運用 |

そのため、公開ページで電話番号を見せる箇所には
**「留守番電話につながります。メッセージを残していただければ折り返します」**の一文を添える。
掲載箇所: `index.html` のメニュー内連絡先(L541付近) / クロージングの「電話してみる」ボタン(L3162付近) / フッター「電話で連絡」(L3251付近)。
※ /budget/ の電話相談バナー（未着手タスク）を作る際も同じ一文を入れること。

## 6. 電話希望が届いたときの初動（見積もりアシスタント鉄則7と同じ）

最初の返信で**お掛けする日時の確定を最優先**に。いただいた時間帯の中から具体的な候補を2〜3個提示して選んでもらう。電話は無料・10分程度・こちらから発信。内容が複雑ならZoom相談（無料）へエスカレーション。
