# HP料金改定 新旧バージョン管理・切り替え手順書

> 作成日: 2026-08-04
> 目的: 新料金体系(v2)への切り替えを好きなタイミングで実行でき、いつでもv1に戻せる状態を保つ。

---

## 1. 新料金体系(v2)の変更内容まとめ

- 2万円LPの基準: 5セクション → **売れる基本7セクション**(ココナラ商品と統一)
- 2万円LPに**標準込み**: メニューバー・ハンバーガーメニュー/簡易お問い合わせフォーム/WordPress納品
- 簡易フォームの線引き: 「お名前・メール・本文程度」。予約システム・会員機能・オリジナル機能開発は別途見積もり(見積もり時に必ず提示)
- 24時間以内ラフ案: 直販もココナラも +5,000円(同条件)
- 納品後の修正・追加: 直接ご依頼の方は 2,750円〜でいつでも継続対応(ココナラは都度購入)
- ココナラ比較セクションを新設(「自由度なら直販/決済の安心ならココナラ」)

## 3. 事前準備(公開前にやっておくと安全)

- [ ] WordPressで非公開の複製ページ「/order-v2/」(公開状態: 非公開)を作り、wp-order-form_v2.html を貼って実物確認
- [ ] ココナラ側の商品ページも7セクション表記であることを確認(現状7なのでOKのはず)
- [ ] 比較セクションのココナラリンク先を決定(★COCONALA_URLコメント箇所。現状はプロフィールページ)

## 4. 切り替え手順(v1→v2)

1. /order/ のカスタムHTMLブロックに wp-order-form_v2.html の全文を貼り替え
2. /price/ に wp-compare-coconala-section.html を追加(+料金表記の5→7セクション修正 ※下記「未完了リスト」参照)
3. service-guide.html に比較セクション追加(静的ファイルなのでGit側で作業)
4. スマホで実際に表示・送信テスト(LINEボタン/メールボタン両方)
5. v2ファイルを「現行」として控えフォルダの運用を更新

## 5. ロールバック手順(v2→v1に戻す)

1. /order/ のカスタムHTMLブロックに v1_現行フォルダの wp-order-form_v1.html を全文貼り直し
2. /price/ から比較セクションのブロックを削除
3. 所要時間: 5分程度。データ消失リスクなし
