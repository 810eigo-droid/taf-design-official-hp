# MailPoet 3通目 コピペ用テキスト版

MailPoetのテキストブロックにそのまま貼り付けるための3通目メールです。

## 件名案

```text
最後に、安心してご注文いただける方法のご案内です
```

## プリヘッダー案

```text
資料請求後のご案内は今回で一区切りです。今後は不定期でWeb制作のお役立ち情報をお届けします。
```
